# Contributing

- This repo is public: write no secrets, personal details or internal URLs. Rules private to one machine go in that machine's `~/.claude/CLAUDE.md`.
- Add rules to AGENTS.md. Put a rule in CLAUDE.md only when it applies to Claude alone.
- One rule per bullet. Add the why when it isn't obvious.
- When AGENTS.md gets long, move a topic to `rules/<topic>.md` and replace it with a one-line pointer saying when to read that file.
- Commit straight to `main`.
